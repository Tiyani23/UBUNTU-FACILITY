IT Security Policy

Purpose

This policy aims to protect the confidentiality, integrity and availability of the organisation's information and IT systems.

Security Guidelines

  • Every user must have their own account.
  • Users must not share passwords or accounts.
  • Use strong and unique passwords.
  • Use multi-factor authentication where available.
  • Access must be approved and match an employee's duties.
  • Lock computer screens when leaving a workstation.
  • Install only approved software.
  • Do not disable security tools or updates.
  • Store work files in approved locations.
  • Protect confidential information from unauthorised access.
  • Report phishing emails, lost devices and malware to IT.
  • Important information must be backed up.

Responsibilities

The IT Manager is responsible for implementing this policy. The Information Security and Data Protection Officer assists with security awareness and compliance.

Policy Review

The policy should be reviewed annually and after major security incidents or system changes.
