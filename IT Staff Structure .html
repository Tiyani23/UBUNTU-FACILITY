IT Department Structure

The IT Manager reports to the Operations Manager. The following positions report to the IT Manager.

IT Manager

The IT Manager oversees the IT department and coordinates the management of the organisation's technology systems.

Network and Systems Administrator

  • Manages servers and computer networks.
  • Manages user accounts.
  • Installs system updates.
  • Monitors networks and performs backups.

Help Desk Technician

  • Records technical support requests.
  • Provides basic technical assistance.
  • Sets up computers and other devices.
  • Updates users about reported problems.

Information Security and Data Protection Officer

  • Promotes security awareness.
  • Reviews user access.
  • Supports incident response.
  • Assists with information protection.

Other Responsibilities

Department heads approve business needs and staff access. All employees must follow IT policies, protect their login details and report suspected security incidents.

In a small organisation, some responsibilities may be combined where practical.
